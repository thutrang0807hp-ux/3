SceneForge v25 · Đăng nhập Flow trên web

Thêm nút mở Chrome/Edge với profile riêng được giữ lại. Vẫn giữ cách kết nối bằng mã.

↓ Tải cập nhật Windows · 3,8 MiB

Đóng phần mềm, cập nhật rồi mở Cài đặt → Tài khoản → Flow/Veo → Đăng nhập Flow trên web. Đăng nhập xong, cài tiện ích trong profile mới rồi kết nối bằng mã để dùng từ app.

Đăng nhập web chưa tự liên kết tài khoản vào app. Chưa khắc phục lỗi Google từ chối tạo video.

Hướng dẫn chi tiết

Đã kiểm tra bằng fixture và Chromium; chưa thử đăng nhập Google thật hoặc updater trên Windows.
