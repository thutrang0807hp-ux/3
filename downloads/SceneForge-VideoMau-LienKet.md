# Truy vết từng bước

| Bước | Giao diện / nguồn | API hoặc dữ liệu | Backend / engine | Tài khoản và đầu ra |
|---|---|---|---|---|
| Chọn video, chọn sản phẩm | app-shell/package6.js: importVideos, scheduleAnalysis | IndexedDB rooms/files; roomPayload; iframe openRoom | chưa gọi nhà cung cấp | Mỗi video có room ID, source riêng, bản sao refs sản phẩm; không có tài khoản vẫn nhập được |
| Xếp phân tích | app-shell/package6.js + workflow/package6-analysis.js | analysisSlots; runAnalysisPipeline | WorkBudget lane analysis | Tối đa hai phòng mở phân tích; CPU đắt được xếp; chưa tự gen clip |
| Đọc/cắt cảnh | workflow/cpu-analysis.js: cpuSubmitFile | POST analysis/local/upload; GET analysis/local/jobs/{id} | cpu_analysis.py → FFmpeg → cpu_worker.py → PySceneDetect | Không tài khoản. Binary 500 MB/10 phút; proxy 480 px/24 fps; mốc cảnh, ảnh bằng chứng và hash nguồn |
| Fallback khi CPU thiếu | workflow/app.js: analyzeSource | Canvas/HTML video, lưu mốc dự án | Trình duyệt so ảnh/histogram | Không phải hiểu ngữ nghĩa; còn thiếu chép lời/OCR sẽ hiện attention |
| Chép lời + OCR + camera | cpu_worker.py, motion.py, speech_guard.py | kết quả local.transcript/scenes | Faster-Whisper CPU int8; RapidOCR; LK optical flow + RANSAC | Model Whisper ở data/models/faster-whisper; không gọi dịch vụ; câu nghi ngờ cần rà |
| Hiểu cảnh, dịch/viết | workflow/package6-analysis.js, analysis-v3.js | POST ai/analyze-frames; Gemini Chat execute_json | frame_analysis.py → gemini_chat.py → gemini_chat_worker.py | Nguồn chọn ở Cài đặt. Chat dùng vault phiên; API key chỉ ở nguồn API riêng. IDs/mốc/câu gốc đối chiếu trước khi áp dụng |
| Dịch riêng | workflow/chat-translation.js | POST gemini-chat/translate | GeminiChat role translation | Giữ mã câu, bản gốc và mốc; cần rà trước khi áp dụng |
| Bộ ảnh tham khảo | app-shell/room payload, workflow/app.js: refsFor/autoConnect | project.refs + scene.refsUsed | UI và asset store | Phải kiểm cảnh nào nối role nào; ảnh thật gửi ở bước viết prompt/tạo ảnh |
| Prompt ảnh theo bộ ảnh | workflow/reference-prompts.js | POST gemini-chat/jobs kind=text, role=writing; GET jobs/{id} | GeminiChat SDK | Ảnh cảnh nguồn + refs; review JSON trước thay prompt; giữ lịch sử, không tự duyệt ảnh |
| Tạo ảnh khung | workflow/direct-providers.js, frame-v3.js | POST gemini-chat/jobs kind=image; GET files/{id} | Gemini SDK GeneratedImage + kiểm file | Tài khoản/selection_token dùng chung; kết quả về đúng scene; gốc giữ, chưa tự approve |
| Duyệt khung | frame-v3.js: frameApproved/approve | kiểm kích thước/nét/nhãn; lưu approvedFrame | frame_quality.py: OpenCV/RapidOCR nếu chọn | Không dùng “AI đã tạo” làm chứng nhận nhãn đúng; sai số đo/nhãn còn cần rà |
| Prompt video sau duyệt | reference-prompts.js + app.js: makePrompt | Gemini text job; visual/motion; speechForPart | Gemini viết theo ảnh đã duyệt; app ghép thoại/voice direction | Bị chặn nếu khung chưa duyệt; JSON không được đổi kịch bản nguồn; lời vắt clip cần chia |
| Chọn tài khoản/số slot | app-shell/account-dispatch.js + accounts-dashboard.js | muse/selection, flow/selection, gemini-chat/selection; concurrency | account_pool.py, video_slots.py, account_settings.py | Dùng riêng / dự phòng / chia việc. Token review đổi khi setting thay. Flow/Muse 1–16 slot/tài khoản; Gemini hiện 1 |
| Tạo clip Flow | direct-providers.js → flow/jobs | FlowProvider → engine loopback /v1/chat/completions, header ID | flow_provider.py → flow_accounts.py → flow_account_engine.py → upstream Flow2API | ID tài khoản engine được ghim bằng ContextVar và phản hồi xác nhận; engine xác nhận số slot trước gửi. API key ở đây là key engine local, không đồng nghĩa key Gemini trả phí |
| Tạo clip Muse | direct-providers.js → muse/jobs | worker riêng, SDK session/media RPC | muse_provider.py → muse_worker.py → Muse SDK | Vault phiên theo hồ sơ; thư mục tạm/job riêng, session ID từ chính events request, không đoán hội thoại gần nhất. Hiện muse.ai, chưa xác nhận meta.ai |
| Kết quả/phiên bản | directRecover; addFrame/addClip | request ledger, files/{id}, room/scene/part | request_ledger.py; ffprobe/Pillow kiểm file | Job ID khác nhau, không gán theo thứ tự hoàn tất. Unknown không tự resend; cảnh đã sửa thì không tự nhập |
| Giọng tùy chọn | workflow/voice-over.js | GET tts/status; POST tts; GET media/{file} | local_tts.py → voice_worker.py → VieNeu ONNX CPU | Không dùng tài khoản online; preset model thật, tạo WAV. Mặc định vẫn tiếng clip; mute/duck cố định được chuyển sang timeline |
| Phụ đề theo audio thật | speech-captions.js + reference-production.js | POST speech/transcribe binary; GET speech/capabilities | speech_captions.py → speech_worker.py → Whisper | Chép lại clip/giọng được chọn, không dịch hoặc thay script nguồn; review cues trước áp dụng. Không phải forced alignment chính xác tuyệt đối |
| Nhạc | reference-production.js | file/thư mục → project.merge.musicLibrary | Trình duyệt đọc file, đặt track | Tắt / bài chỉ định / ngẫu nhiên trong danh sách đã nhập; không tự tải nhạc |
| Sang Dựng | workflow/room-shell.js: openInEditor | workflow-open-editor → shell → editor workflow-import | native-preview/workflow-import.js | assembled cần đủ clip; library cho tự ghép; mang file, phiên bản, captions, voice, music và clipVolume |
| Xuất MP4 | native-preview/timeline-export.js | local-api/timeline/* hoặc bộ xuất browser | timeline_export.py / exports.py → FFmpeg | Không gọi AI; giữ trạng thái job và file xuất; app shell nhận kết quả export cập nhật phòng |

Tên API đầy đủ/method/file backend được lấy từ app tại `routes.json`; bảng trên mô tả hợp đồng, không thay cho chứng cứ live-provider.
