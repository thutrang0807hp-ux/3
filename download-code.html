Cài SceneForge trên Windows

Bản chạy thử cho Windows 10/11 · 64-bit, kèm Python và thư viện cơ bản. Tải file EXE, mở để cài, rồi mở SceneForge từ shortcut. Kho kịch bản v5 đang tạm hoãn.

SceneForge-Setup-Windows-x64.exeKhoảng 84 MB · Bộ cài cho người dùng hiện tại · Không cần cài Python riêng
↓ TẢI BẢN CÀI .EXE

1. Tải file EXE và mở để cài.
2. Cài xong, mở shortcut SceneForge trên Desktop hoặc Start Menu.
3. Giữ cửa sổ dòng lệnh của SceneForge khi sử dụng; đóng cửa sổ để dừng app.

Bản thử nghiệm chưa ký số. Tài khoản AI, model Whisper/VieNeu và FFmpeg/ffprobe cần thiết lập riêng. Start Menu có mục “SceneForge - Cai Whisper” để tải model khi cần. Dữ liệu cũ của bạn được giữ.
