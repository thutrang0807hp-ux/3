Cài SceneForge trên Windows

Bản v2 cho Windows 10/11 · 64-bit. Chọn nơi cài, dữ liệu và cache trước khi giải nén. Có Python, FFmpeg, công cụ CPU và Whisper base. Kho kịch bản v5 vẫn tạm hoãn.

↓ TẢI BẢN CÀI WINDOWS v2

1. Tải và mở EXE, chọn thư mục rồi Cài đặt. Lần đầu có thể mất vài phút.
2. Mở SceneForge từ Desktop / Start Menu.
3. Đăng nhập tài khoản AI của bạn trong app.
Gỡ bằng Windows Apps hoặc “Gỡ SceneForge”; mặc định giữ dự án và model.

Giữ cửa sổ dòng lệnh của SceneForge khi dùng; đóng để dừng. Cần Chrome hoặc Edge. Gemini/Flow SDK được chuẩn bị mặc định; tài khoản AI do bạn đăng nhập. Giọng VieNeu là tùy chọn tải thêm trong “Công cụ và kiểm tra”. Bản thử chưa ký số; chưa kiểm tạo media bằng tài khoản online.
