# SceneForge .158

Replace transform scaling with CSS layout zoom in both creation canvases: workflow and photoWorld. Glyphs, borders and controls are laid out/rasterized for the requested zoom instead of applying a scale transform to the whole world. Keep a translation-only transform divided by zoom so screen-space camera panning is unchanged. Preserve the original transform-scale path for runtimes without CSS zoom. Redraw wires only when zoom changes because layout rounding can alter node height; ordinary panning does not redraw wires. Camera persistence, pointer delta division, offset-based wire routing and minimap coordinates remain in existing world units. No image upscaling, added runtime or cache.

Verification uses actual Chromium pages, opens sample video and an image-to-video room fixture, checks node screen positions/dimensions at 50/100/170%, pointer hit tests and drag movement before collision-placement on release. Captured visible node screenshots and inspected text. CSS layout zoom can cause minor font wrapping/height differences; actual Windows WebView rendering not tested. The updater covers .62 onward and preserves every .157 file except workflow.html and photos.html.
