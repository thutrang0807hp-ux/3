# .108 — AI writing workbench in the Script Library

User flow: Kịch bản → AI viết giúp → brief/product/facts/duration → optional clarifying questions or three full drafts → select/edit → save a new library document → use the existing independent photo-room copy flow. The photo script node and its existing AI write action are unchanged. The new workbench is within the library editor pane, with the brief collapsed after results and optional audience/tone/voice-sample fields. Requests, drafts and per-variant edits persist; close/Ctrl+S flush the debounce before confirming storage.

New compose action uses the existing configured Gemini Chat/API transport and durable request ledger. One provider request returns all three drafts, rather than a five-request pipeline. On insufficient facts, up to three targeted questions are returned. Vietnamese retail instructions are original: source-grounded claims, natural spoken language, distinct openings, no invented personal reviews/testimonials/discounts, optional personal voice, estimated Vietnamese speech timing. Output schema validation is not a factual guarantee: users review before saving/using.

The original prompt design draws on general workflow ideas reviewed in Melvynx/video-agent-skills (studio-script: hook alternatives, voice and editing), coreyhaines31/marketingskills (product/audience evidence and clear copy), and but001/short-form-video-script-agent (structured scene workflow). No repository runtime, model, third-party prompt text or pipeline code is vendored. No new model/download dependencies.

Existing write/split/topics contracts stay intact. Compose uses the explicit button as send authorization; the other actions retain their existing confirmations. A lost response can recover the same request without provider redispatch, or the user can explicitly start a new request. Navigating away while waiting does not take the tab back; results are retained. Saving always creates a separate document and existing video use makes its own copy.

Validation: actual Chromium + IndexedDB/SQLite and fixture AI cover brief→question→three drafts, variant selection/edit retention, immediate storage flush, library save, independent room copy, lost-response recovery without redispatch, and late-response navigation. Existing tab/close regressions pass. No live Gemini-generated script-quality test or native Windows installer test. Web UI source is scripts/ui/script_composer.js, embedded identically in both entry pages and verified by the builder.
