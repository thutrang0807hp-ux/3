# Fresh Windows installation · v46.129

A single online setup, separate from the .129 update for an existing installation. It downloads the pinned official SceneForge v2 installer from its existing GitHub release (553,209,693 bytes), verifies its complete SHA-256, then extracts and verifies the original appended payload. The original setup is not executed. Before moving the new release into place, it overlays the full current backend, reviewed web pages, bootstrap/extensions and native window dependencies. All overlay bytes are checked against the embedded manifest. No minimum previous patch is required.

The installer preserves the established per-user folder picker, explicit data/cache paths, cancellation, local core provisioning, optional voice setup, shortcuts and Programs and Features registration. New installation directory is `releases/2026.11.14.46129`; the original `installation.json.payload_sha256` identifies the verified original base payload, while `fresh-code-manifest.json` identifies the applied code overlay. `app-build.json` records .129 so later cumulative updates can recognize it. Existing release folders and project data are not overwritten or migrated. Reusing an occupied .129 folder from another package is blocked.

A missing WebView2 Runtime is installed from Microsoft's official bootstrap URL after checking Authenticode status and Microsoft signer. WebView2 managed DLLs and loader come from the same Microsoft SDK used to compile the existing native host; licenses are bundled. The online setup needs working GitHub access, plus Microsoft access when WebView2 is missing. Chrome is needed for the current GFlow profile path. Preparing optional voice can download further dependencies/models.

The base already includes Python, FFmpeg/ffprobe and Whisper base; this is not a model-free package. Setup is around 91 MB including the original GFlow CLI archive; during setup it additionally downloads around 553 MB. Allow at least 4 GB free for unpacking, tools and initial data. No user accounts, cookies, project assets or private profiles are bundled; sign in again on the new PC and restore projects separately from a backup. Downloading the application cannot restore lost projects.

Verification performed: pinned original installer SHA-256 and ZIP CRC; coverage of every latest recorded patch file; per-file overlay hashes; all merged Python sources compile; embedded executable resource/ZIP byte equality; unchanged generic launcher code; PowerShell syntax parser. These are packaging checks, not a successful installation on a fresh Windows PC. No Windows execution or live account/media generation was performed for this setup. Base installer v2 had a historical Windows report, which does not certify the new overlay/setup.

Build: `PYTHONPATH=/path/to/dnfile python scripts/windows-fresh-install/build.py --base /path/to/SceneForge-Setup-Windows-x64-v2.exe`. Output: `downloads/windows-fresh-129/`. Base URL and hash are fixed in the build/setup, not taken from arbitrary input. Requires the official WebView2 DLLs next to `veo-node-v46/windows-desktop/SceneForge.exe`.
