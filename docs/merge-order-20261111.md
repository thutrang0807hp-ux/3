# SceneForge .117 — Assembly clip order

Original helper scripts/ui/merge_order.js embedded in workflow only. merge.clipOrder stores JSON [sceneId,partId] keys, normalized against live parts, retaining legacy merge.order as seed. Source scenes, original order metadata, prompts, IDs and generation receipts untouched. Native HTML drag is scoped to assembly items and room; Alt arrows and modal up/down provide alternatives. Bounded history supports undo; original-order reset uses natural source scene order. Media files are never modified or deleted.

Assembly node, caption preview payload, cut rows and clip-audio transcription sources use ordered rows. preparePayload applies order before duck/cut/export processing; existing decoder/render/export paths receive new clip starts. Generated base captions map legacy order into current clip order. Custom cues remap on move and keep manual fields; crossing-boundary text partitions by word count proportional to overlap, retaining every word once. This is approximate timing, not forced alignment. Unedited custom captions restore exact prior snapshot on undo; later edits are retained and reverse-mapped. Caption validity guard updates only if previously current; pre-existing stale/audio-changed flags remain.

Separate voice uses immutable source file and per-clip sourceIn/start/duration windows. Source layout captured in natural scene order for a given voice asset; a newly created voice does not inherit stale reordered source offsets. Unchanged order leaves continuous voice intact. Changed layout is rejected when the stored voice mapping cannot be resolved. Native clip audio moves with clip. Background music remains continuous. Duck guide generation now respects each voice segment's start/source offset. Cuts operate after ordering. Order changes are blocked during open playback/export or active audio work, and do not auto-generate media.

Validation: check_merge_order.py runs real drag_to and keyboard in Chromium; real 8s green/red MP4 and 16s WAV. Checks saved order restore, unchanged source IDs/script, manual cue timing, voice offsets [8,0], actual first red pixel in assembly playback after move, undo, cross-boundary word conservation, new-voice offset reset and independent a/b order. Existing check_caption_video_viewer_ui.py regression passed across workflow/photos. Inline scripts parse and installer embedded source/checksums verified. No Windows GUI/updater or full backend final render run in this task.
